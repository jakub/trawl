# Trawl 0.9.5

Trawl collects and searches logs for homelabs and small installations. Run one
Linux server, send it events over HTTP or syslog, and search them from a browser,
the command line, or the terminal UI.

This is a release candidate for 1.0. The live tail and the `extract kv` tail
now read globs, regex classes, calls, and timestamps the same way stored search
does. trawld refuses query text that could abort it, and it caps scheduled and
manual report runs. A saved token now goes only to the URL it was saved for.
The CLI and the TUI no longer pass terminal control characters from stored
events to your terminal. Releases no longer ship `trawl-admin`.

Read [Existing installations](#existing-installations) before you upgrade.
The app database takes a migration that 0.9.4 cannot read, ingest now
replaces some event times, and some stored query text stops parsing.

## What is included

- The histogram above search results counts the whole result, not only the
  rows on the page. trawld counts it in the same request as the page. API
  clients ask for it with `"histogram": true` on `POST /api/v1/query`.
- Exports are tracked like queries. `GET /api/v1/queries` lists a running
  export, `DELETE /api/v1/queries/{id}` cancels it, and a successful export
  writes a query history row and counts in `total_queries` and
  `trawl_queries_total`. To cancel an export, a key needs `query_cancel`.
- A cancel by id now reaches a query, an export, or a capture that still waits
  to start. The cancelled request answers 503 `service_unavailable`.
- Scheduled runs in flight are capped at `max(1, max_concurrent_queries / 2)`,
  so schedules cannot take every executor permit. A due schedule past the cap
  waits for a later poll, and its missed boundaries coalesce into one run.
- Manual runs (**Run now**) are capped at one per key and
  `max(1, max_concurrent_queries / 4)` across the installation. Past either
  limit, Run now answers 429 `manual_run_busy` with `Retry-After`, and claims
  nothing. `/metrics` adds `trawl_net_run_leases_in_use{origin}` and
  `trawl_net_run_lease_limit{origin}`, with `origin` set to `scheduled` or
  `manual`. None of these limits has a setting.
- The scheduler lists only schedules that can still start a run. A paused or
  spent schedule costs a poll nothing. A claim and each page of the due
  listing wait at most 5 seconds for their database locks.
- A filter that names several services, such as `service=a,b` or
  `(service=a OR service=b)`, reads only those services' files. A capture's
  `capture_source_too_large` refusal now suggests pinning services.
- trawld's own events at INFO and above name a failure by its closed
  `error_class` and `cause_kind`. They no longer carry driver, engine, or
  operating-system error text. That text goes to a DEBUG event with the same
  `event_type`. [Read the error text of a
  failure](https://trawl.sh/operate/health/#read-the-error-text-of-a-failure)
  shows how to see it. Every server error also has one public message, on the
  wire and in stored report-run and repin-job rows.
- Investigations: `PATCH /api/v1/investigations/{id}` and the finding status
  route take an optional `seen_seq` and answer the activity since it. In
  `trawl mcp`, `status` and `finding_status` print that activity. A step whose
  capture was cut records `total_rows`, and the browser says the step was
  cut. The evidence budget refusal names the budget that refused.
- MCP: `read` takes a `columns` list, and a wide result now prints rows by
  first omitting columns that are null in every row read. The hard-cap
  refusal names a route that works. `orient` names the `matches` operator and
  literal `replace`, and tool schemas carry only standard formats. The
  never-observed field hint also checks the fields that stages read.
- The DSL accepts `AND`, `OR`, and `NOT` in capitals inside expressions. The
  formatter prints them in lowercase.

## Fixes

### Query language

- A glob matches bytes, as DuckDB's `GLOB` does, in every lane. `?` matches
  one byte, so `é` needs `??`. `[!4]` negates a class, and `[^4]` matches `^`
  or `4`. A malformed glob, such as `a[b*` or `[z-a]*`, matches no value.
  Before, the live tail read `[^4]*` as "does not start with 4".
- `\d`, `\w`, `\s`, `\b`, and `\B` are ASCII in the live tail and the
  `extract kv` tail, as they already were in stored search. `/\w+/` no longer
  matches `é` there. Write `\p{Nd}` for Unicode digits.
- Behind `extract kv`, a TIMESTAMP column compares as an instant.
- Every `earliest=` and `latest=` clause is checked. A bound that cannot be
  read, such as `earliest="yesterday"` or a year past 9999, is a parse error,
  and so is `last=` beside a bound. A bound reads as wall clock in both the
  live tail and batch. Before, the live tail ignored a bound it could not
  read, so `earliest="2026-03-14"` matched every event.
- An aggregate in `where` or `let`, or nested in another aggregate, is
  refused in every lane with one sentence. A scalar head such as
  `stats lower(x)` runs only in batch SQL. The live tail no longer counts rows
  for it.
- Validation, saving, and every run check each call in every stage: its name,
  its argument count, and its literal arguments. `where match(message, "x")`
  used to pass `/api/v1/validate` and fail only when it ran. `/api/v1/stream`
  answers a bad call with 400 `validation_error`.
- One expression, or the search, is at most 64 levels deep. Brackets or `NOT`s
  nested more than 512 deep are refused before parsing. Before, a deeply
  nested or very long flat query could overflow the stack and abort trawld.
  Any key with `query` could send one.
- One `sort` or `dedup` stage names at most 64 fields. A kv-tail `sort` over a
  column that mixes numbers and number-led text no longer panics.

### Server

- Ingest replaces a `_time` more than 15 minutes after arrival with the
  arrival time and records the actionable repair `time.ahead_of_arrival`. This
  applies to HTTP and syslog. A source field such as `timestamp` keeps the
  sender's value. Before, trawld kept a time up to one day ahead.
- trawld refuses a schedule `max_runs` above 9223372036854775807 with 400
  `bad_request`. Before, it stored 9223372036854775807.
- The stats loop keeps running after a failed gauge collection or a panicked
  storage scan.
- A path under the data root whose absence trawld cannot prove, such as one
  below a dangling link, is an error, not an absent file.
- Rollup recovery finds markers under any directory of an environment. A
  marker in a directory whose name is not a `YYYY-MM-DD` date is reported as
  `day_not_canonical` and left alone.
- Saved-query name refusals have their own codes: 400 `invalid_name` and 409
  `duplicate_name`.

### CLI, TUI, and trial

- A saved token goes only to the URL it was saved for. Before, `--url` or
  `TRAWL_URL` could send the `[server]` token, or `TRAWL_TOKEN`, to another
  server. A new global `--token-file PATH` reads a key from a file. See
  [where a token goes](https://trawl.sh/reference/cli/#where-a-token-goes).
- `trawl query`, `trawl schema`, `trawl driver`, the TUI, and trawld's
  monitor do not write control, bidirectional, or zero-width characters from
  stored events to a terminal. A table and a CSV on a terminal show them as
  `�` or as escapes. JSON on a terminal escapes them as `\uXXXX`. Output to a
  pipe or a file keeps the stored text, so a later command that prints it to a
  terminal can show them.
- Terminal text is measured by grapheme and display cell. Wide characters,
  emoji, and combining marks no longer push columns out of line, and query
  error carets point at the right column.
- `ui.timezone` is the zone of the machine that runs the client. `local` reads
  the offset at each instant, so it follows daylight saving time, and every
  printed instant carries its own offset. The TUI shows every instant in this
  zone. An invalid value is a usage error before any request, and the TUI
  leaves no `tui.log` behind.
- A TUI schedule edit keeps `max_runs` and `enabled`.
- `trawl trial up` generates the trial's certificate itself. Existing trials
  resume.

### Web UI

- Every investigation board read waits out a 429 `Retry-After`, including
  **Refresh** and **Load more entries**. A 403 stops the board and removes the
  controls that would read it.
- The SPA reads every failure through one decoder and sends you to sign in on
  a 401.
- **Run now** and run result rows appear only for a session that holds
  `query` beside `saved_query`.
- **Open result** and **View rows** on investigation rows have their button
  styles again.

### Packaging

- Releases no longer ship `trawl-admin`. trawld generates its self-signed
  certificate on its first start, and `trawl trial up` generates the trial's.
  Linux archives, the Debian `trawl-server` package, and the container image
  hold `trawld`, `trawl-web`, and `fleet-admin`. The CLI archive and
  `trawl-cli` hold `trawl`.
- The Helm chart takes each container port from the address it serves. Before,
  the ports stayed at 5514, 1514, and 8090 whatever the addresses said.
- tokio goes to 1.53.3 for RUSTSEC-2026-0386. rmcp is pinned to 3.9.0 for
  RUSTSEC-2026-0462. Trawl does not run the affected rmcp client code.

## Breaking changes for API clients

- `POST /api/v1/query` no longer has a `timezone` field. trawld ignores the
  field and answers every timestamp in UTC with a `Z`. A client that wants
  another zone converts `timestamp` cells itself.
- `POST /api/v1/saved/{id}/run` and `GET /api/v1/saved/{id}/runs/{run_id}`
  need `query` as well as `saved_query`. A key with `saved_query` alone gets
  403 `forbidden`. It can still list runs.
- A second **Run now** while the key's own manual run is in progress gets 429
  `manual_run_busy`, not 409. A 409 `bad_request` now means a scheduled run
  of that net is in progress.
- `PATCH /api/v1/investigations/{id}` answers `{investigation, entry,
  activity}`, not the bare investigation. `activity` is present only when the
  request sends `seen_seq`.
- Saved-query name refusals use `invalid_name` (400) and `duplicate_name`
  (409), not `bad_request`.
- trawl-web answers its own refusals with the error envelope,
  `{"error": {"code": ..., "message": ...}}`. The bare `{"error": "..."}` body
  is gone. Upgrade trawl-web and the CLI together, or
  `trawl doctor --web-url` reports `web.origin` as failed.
- In `trawl mcp`, the activity mirror's `more` is now `trawld_holds_more`.
- trawld's retained events carry `error_class` and `cause_kind` where they
  carried an `error` text. A saved query or an alert over `service=trawld`
  that reads that text needs the new fields. Events stored before the upgrade
  keep their text until retention removes them.

Upgrade trawld, trawl-web, and every `trawl` CLI together.

## Existing installations

0.9.5 keeps the 0.9.0 storage epoch. The server applies the app-database
migration at startup. 0.9.4 refuses to start against a database that holds
it, so a rollback means restoring a backup.

### Back up first

1. Stop trawld cleanly.
2. With trawld stopped, run `pg_dump` on the app database and the auth
   database. At the same time, copy the data root, including `wal/` and
   `scheduled/`, and `[server] results_dir`.
3. If a `.rollup-*` marker sits in a data-root directory whose name is not a
   `YYYY-MM-DD` date, move that directory out of the data root. 0.9.5 reports
   such a marker as `day_not_canonical` and changes nothing in it.

All three parts are needed for a rollback. A dump of the app database alone
does not match a corpus that 0.9.5 has since written to. Events ingested by
0.9.5 with a time more than 15 minutes ahead are stored at arrival time, and a
rollback does not restore their original `_time`.

### Databases

- The app database gains the index `schedules_due_idx`, through the migration
  `20261111000001_schedules_due_idx`. trawld applies it at startup.
- The auth database does not change. 0.9.5 adds no permission, and
  `fleet-admin migrate` has nothing new to apply.
- A key that runs nets or reads run rows with `saved_query` alone needs
  `query` too. The `trawl-reader` role in
  [Manage access](https://trawl.sh/operate/access/) already holds both.
- Stored query text can stop parsing under the query-language fixes above.
  Saved queries, schedules, investigation steps, and the queries behind
  captured results keep their text. A scheduled run of such a query records a
  failed run with the reason, and its schedule stays enabled. Open these
  queries after the upgrade and fix any that report an error. Look for
  unreadable time bounds, `last=` beside a bound, aggregates in `where` or
  `let`, unknown calls, more than 64 fields in a `sort` or `dedup`, and deep
  nesting. Also check globs and regex classes that relied on the old live-tail
  reading, and fields named `AND`, `OR`, or `NOT`. Write `` `NOT` `` to keep
  such a field.

### Configuration

Run `trawld --check-config` before you start 0.9.5.

- These task periods must be greater than 0: `[ingest] stats_interval_secs`
  and `telemetry_flush_interval_secs`, `[retention] retention_interval_secs`,
  `[scheduler] poll_interval_secs`, and `[server] schema_cache_ttl_secs` and
  `monitor_refresh_ms`. trawld refuses a 0 at load. Before,
  `stats_interval_secs = 0` turned stats off. Set a period instead. The same
  rule applies to the matching Helm values.
- No configuration key is added or removed.

### CLI configuration

- A profile whose `url` names another server needs its own `token`. `trawl`
  no longer sends the `[server]` token there. The same holds for `--url` and
  for `TRAWL_TOKEN` with a different `TRAWL_URL`. `trawl` refuses before it
  sends anything, and the message names `--token` and `--token-file`.
- Every `url` must be an `http` or `https` URL with a host. `trawl` refuses a
  URL with credentials, a query, or a fragment.
- `ui.timezone` accepts `UTC` and `local` in any case, or exactly `+HH:MM` or
  `-HH:MM`. Fix a looser spelling such as `+5:30`.

### Helm chart

- `config.server.httpAddr`, `web.bindAddr`, `config.syslog.udpAddr`, and
  `config.syslog.tcpAddr` must end in `:<port>`. An address without a port
  fails the render. The syslog addresses are checked only when syslog is
  enabled.
- Each container port now matches its address. If you changed a listen port,
  the Service now reaches it.
- The image no longer contains `/usr/bin/trawl-admin`.

### Debian

- Upgrading `trawl-server` removes `/usr/bin/trawl-admin`. trawld still
  generates its own certificate on its first start. Remove `trawl-admin` from
  any script that called it.
- The systemd units and the Vector configurations do not change.

## Installation choices

| Platform | Available components |
| --- | --- |
| Linux amd64 and arm64 | Server and CLI archives, Debian packages, and container images |
| macOS 15 or newer, Apple silicon and Intel | CLI archives |
| Kubernetes | Helm chart for the Linux server and browser |

Linux packages target Debian 12. Archives include the DuckDB runtime. Keep
their `bin/` and `lib/trawl/` directories together. Linux archives hold four
executables: `trawld`, `trawl-web`, `fleet-admin`, and `trawl`. macOS archives
use ad-hoc signatures and are not Apple Developer ID signed or notarized.

Start with the [installation guide](https://trawl.sh/getting-started/) and
[your first query](https://trawl.sh/getting-started/first-query/).

## Requirements and scope

A server needs persistent storage and PostgreSQL, with separate databases for
authentication and application state. Clients need an API key with the required
permissions and trust in the server's TLS certificate. The browser requires
its own public origin and persistent session key.

Trawl is designed for one node. It does not provide clustering, sharding, or
multi-tenancy. Storage and memory needs depend on ingest volume, retention,
and queries.
