## Status meanings

- **Open**: implementation or a specific disposition remains.
- **In progress**: an assigned change is being implemented or verified.
- **Awaiting decision**: a product or architecture choice is needed; independent work continues.
- **Awaiting authorization**: an external action is needed; preparation can continue.
- **Locally verified**: the recorded local checks passed; review/delivery status is stated separately.
- **Verified; retain**: the existing behavior/artifact satisfies the audit's recommendation to keep it.
- **Complete**: required implementation, reviews, evidence, and authorized delivery are recorded. A partial check never establishes this status.
