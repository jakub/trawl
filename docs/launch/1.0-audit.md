# Trawl 1.0 launch audit

Audited on 2026-09-13 against `a3422a69d3a989816d1de8446bf9212fe8b4ccc8`. Local `main` and GitHub `main` matched. This report treats the reader as someone who has never used Trawl.

The public manual already explains much of the current product. The larger remaining problems are in shipped examples, installation output, release distribution, and executable accommodation for pre-1.0 states. Some examples have functional defects that a wording pass would miss.

This is an audit and a proposed scope. No repository files, branches, tags, releases, issues, packages, or deployments were changed. The report itself is outside the checkout. No build, application, installer, Vector pipeline, or browser test was run.

## Recommended launch contract

Treat 1.0 as the first supported installation baseline. Its normal installation path starts with empty application state and teaches the product as it exists at launch. It should not ask readers to understand SQLite, previous token models, ADR slices, former envelope fields, or earlier UI migrations.

Existing personal installations need a separate, explicitly chosen disposition before incompatible code changes are applied to them. A fresh-start product policy does not authorize resetting those installations or a shared Fleet database.

Keep the mechanisms that protect current and future installations: schema initialization and subsequent migrations, storage-format identification, refusal of unsupported formats, catalog identity, crash recovery, repin recovery, persistent session keys, backup and restore, and single-writer enforcement. The format number does not need to become `1` merely because the product version becomes 1.0.

## Findings that affect installation or delivered behavior

### L01. Public distribution is a launch decision that remains open

GitHub reports `jakub/trawl` as private and its Pages site as public, with `trawl.sh` as the CNAME. The installation guide sends readers to GitHub Releases and downloads assets with unauthenticated `curl`.

For a public launch, provide accessible release assets and source links under the intended distribution model. Repository publication is one option, not an action authorized by this audit. Private metadata establishes the access restriction; an anonymous asset download was not attempted.

Evidence: [installation guide](https://github.com/jakub/trawl/blob/a3422a69d3a989816d1de8446bf9212fe8b4ccc8/docs/src/content/docs/getting-started/index.md#L41), live repository and Pages metadata.

### L02. Documentation and normal downloads describe different development points

The docs workflow deploys from `main`. The latest GitHub release is `v0.4.0`, published on July 24, and both APT architectures offer `0.4.0-1`. Current main is 133 commits beyond that tag and still declares workspace version `0.4.0`. The source build has Git metadata, but the package version alone cannot distinguish these states.

For launch, align the stable manual, binaries, image, chart, and examples to one release commit. Label any development documentation separately. The audit did not compare every currently served HTML page with its installed binary behavior.

Evidence: [docs deployment](https://github.com/jakub/trawl/blob/a3422a69d3a989816d1de8446bf9212fe8b4ccc8/.github/workflows/docs.yml#L41), [workspace version](https://github.com/jakub/trawl/blob/a3422a69d3a989816d1de8446bf9212fe8b4ccc8/Cargo.toml#L7), live release and APT metadata.

### L03. Manual release reruns can mix source revisions

Linux and macOS builds check out `RELEASE_TAG`. The Docker and Helm jobs do not specify that ref. Dispatching the workflow on main for another tag can therefore combine tagged binaries with the selected branch's Dockerfile and chart, while publishing the requested version number.

Resolve one release commit and use it for every source-consuming job. Check the final artifact versions and provenance before publishing. This is a source-level workflow defect; the workflow was not executed.

Evidence: [Linux checkout](https://github.com/jakub/trawl/blob/a3422a69d3a989816d1de8446bf9212fe8b4ccc8/.github/workflows/release.yml#L36), [Docker checkout](https://github.com/jakub/trawl/blob/a3422a69d3a989816d1de8446bf9212fe8b4ccc8/.github/workflows/release.yml#L421), [Helm checkout and packaging](https://github.com/jakub/trawl/blob/a3422a69d3a989816d1de8446bf9212fe8b4ccc8/.github/workflows/release.yml#L477).

### L04. The supported APT index still advertises the retired daemon package

Both live APT indexes offer `trawld 0.1.0-1` alongside `trawl-server 0.4.0-1` and `trawl-cli 0.4.0-1`. A user searching for the executable's name can select the original package. The release workflow scans the accumulated pool, which preserves obsolete package names in the current index.

Remove the retired package name from the supported index during authorized distribution cleanup, and make regeneration preserve that decision. Historical package files can remain outside that index if they are useful. Do not delete the active publication branch.

Evidence: [APT index generation](https://github.com/jakub/trawl/blob/a3422a69d3a989816d1de8446bf9212fe8b4ccc8/.github/workflows/release.yml#L356), the amd64 and arm64 `Packages` files read from `gh-pages` through the GitHub API.

### L05. Helm installation output directs users to nonexistent bootstrap tokens

`NOTES.txt` tells users to retrieve first-install API tokens from `init-auth` logs. That container runs only `fleet-admin migrate`, which does not create keys. The current chart README gives different, correct provisioning guidance.

Make installation output identify the actual next step: create the required roles and keys, then sign in with a personal key. Clearly distinguish schema initialization from credential creation.

Evidence: [post-install token instructions](https://github.com/jakub/trawl/blob/a3422a69d3a989816d1de8446bf9212fe8b4ccc8/chart/trawl/templates/NOTES.txt#L5), [init container command](https://github.com/jakub/trawl/blob/a3422a69d3a989816d1de8446bf9212fe8b4ccc8/chart/trawl/templates/statefulset.yaml#L45).

### L06. The chart advertises cert-manager behavior it does not implement

`tls.mode=certManager` says it creates a Certificate and accepts an issuer reference. No Certificate template exists. The pod expects a TLS Secret, and the README explains that the operator must create the Certificate and that issuer options are unused.

Choose one contract. The smaller launch change is to accept an operator-managed TLS Secret and remove the inert issuer options. Alternatively, implement and verify Certificate creation. Both the values and the README must describe the same behavior.

Evidence: [TLS values](https://github.com/jakub/trawl/blob/a3422a69d3a989816d1de8446bf9212fe8b4ccc8/chart/trawl/values.yaml#L239), [chart TLS reference](https://github.com/jakub/trawl/blob/a3422a69d3a989816d1de8446bf9212fe8b4ccc8/chart/trawl/README.md#L131). This conclusion is from all chart template filenames and relevant references, not a Kubernetes deployment.

### L07. Helm verification and access instructions contradict the image and routes

The health command invokes `wget` inside an image that does not provision it. HTTPRoute output says “Web access,” but its backend is the daemon API port. Ingress output also says “Web access” when the configured backend is `trawld`.

Use the existing local port-forward and local `curl` verification path. Print separate API and browser addresses based on the actual backend. If browser HTTPRoute support is desired, make it an explicit supported option.

Evidence: [installation output](https://github.com/jakub/trawl/blob/a3422a69d3a989816d1de8446bf9212fe8b4ccc8/chart/trawl/templates/NOTES.txt#L10), [image contents contract](https://github.com/jakub/trawl/blob/a3422a69d3a989816d1de8446bf9212fe8b4ccc8/Dockerfile#L11), [HTTPRoute backend](https://github.com/jakub/trawl/blob/a3422a69d3a989816d1de8446bf9212fe8b4ccc8/chart/trawl/templates/httproute.yaml#L18). Published image contents and actual routing were not executed.

### L08. The Debian Vector topology duplicates journal events and bypasses its filter

The HTTP sink selects `trawl_*`. This matches both `trawl_journal_enriched` and `trawl_journal`, although the latter filters the former. The resulting graph sends accepted journal events along two paths and filtered events along the intermediate path.

Select only final outputs, or give intermediate transforms names outside the sink's match pattern. Verify one accepted event produces one delivery and one rejected event produces none. This is a source-topology inference, supported by Vector's documented wildcard input behavior; Vector was not run.

Evidence: [intermediate transform](https://github.com/jakub/trawl/blob/a3422a69d3a989816d1de8446bf9212fe8b4ccc8/config/vector/debian/base.toml#L90), [filter](https://github.com/jakub/trawl/blob/a3422a69d3a989816d1de8446bf9212fe8b4ccc8/config/vector/debian/base.toml#L196), [sink input](https://github.com/jakub/trawl/blob/a3422a69d3a989816d1de8446bf9212fe8b4ccc8/config/vector/debian/base.toml#L269), [Vector input reference](https://vector.dev/docs/reference/configuration/pipeline-components/).

### L09. The optional UniFi TCP source is not connected to forwarding

The example invites users to uncomment `unifi_syslog_tcp`. Its normalizer still consumes only `unifi_syslog`. The sink consumes normalized transforms, so the new TCP source has no path to it.

Make the example change include the transform input, or ship a complete selectable TCP configuration. Verify an event reaches Trawl through each advertised transport.

Evidence: [optional source and normalizer](https://github.com/jakub/trawl/blob/a3422a69d3a989816d1de8446bf9212fe8b4ccc8/config/vector/debian/unifi-syslog.toml#L27).

### L10. UniFi instructions mix the native syslog and Vector HTTP paths

The Vector fragment suggests using trawld's `source_service_map` as an alternative to its remap. That setting belongs to trawld's native syslog listeners. This collector forwards through HTTP, so the advice does not name the mechanism that processes those events.

Explain the two choices directly: device to trawld uses the daemon mapping; device to Vector uses Vector's mapping before HTTP forwarding.

Evidence: [fragment advice](https://github.com/jakub/trawl/blob/a3422a69d3a989816d1de8446bf9212fe8b4ccc8/config/vector/debian/unifi-syslog.toml#L15), [HTTP destination](https://github.com/jakub/trawl/blob/a3422a69d3a989816d1de8446bf9212fe8b4ccc8/config/vector/debian/base.toml#L270), native syslog UDP and TCP source-map callers.

### L11. The standalone Vector setup header omits config-directory selection

The header says to copy files into `/etc/vector/vector.d/` and start Vector, but does not set `VECTOR_CONFIG_DIR`. The current manual includes that variable and explains that it replaces the package's default configuration file.

Either provide the complete setup in the header or link to one canonical procedure. Do not maintain a shorter, incomplete second installation recipe.

Evidence: [example setup](https://github.com/jakub/trawl/blob/a3422a69d3a989816d1de8446bf9212fe8b4ccc8/config/vector/debian/base.toml#L3), [complete manual setup](https://github.com/jakub/trawl/blob/a3422a69d3a989816d1de8446bf9212fe8b4ccc8/docs/src/content/docs/getting-started/vector-integration.md#L56). Package startup behavior was not run.

### L12. The macOS local Vector quick start uses an obsolete CLI shape

Its examples invoke top-level `--data` and a positional query. Current `--data` belongs to `trawl query`. The example also generates NDJSON, while the current embedded command advertises Parquet. Changing command word order alone does not establish a working example.

Retire this old recipe or rewrite it around a supported ingest-to-Parquet path, then execute every printed command. Decide whether a macOS development example belongs in the launch documentation at all.

Evidence: [old commands](https://github.com/jakub/trawl/blob/a3422a69d3a989816d1de8446bf9212fe8b4ccc8/config/vector/local-dev.toml#L13), [current CLI definition](https://github.com/jakub/trawl/blob/a3422a69d3a989816d1de8446bf9212fe8b4ccc8/crates/trawl-cli/src/lib.rs#L60).

## First-use improvements

### N01. Complete the first-install tutorial through the browser

The tutorial provisions PostgreSQL, starts trawld, and demonstrates CLI, TUI, and export. It omits `trawl-web` from the required executables, never starts the proxy, then links to browser reference material “once you have a browser URL.” A new installer still has to discover how to obtain that URL.

Finish the tutorial with a running proxy, its exact local origin, sign-in using the tutorial's personal key, and a browser query over the known events. Include proxy shutdown in cleanup. Keep deployment reference details outside the tutorial, but do not omit a prerequisite to its advertised result.

Evidence: [prerequisites](https://github.com/jakub/trawl/blob/a3422a69d3a989816d1de8446bf9212fe8b4ccc8/docs/src/content/docs/getting-started/first-query.md#L10), [browser handoff](https://github.com/jakub/trawl/blob/a3422a69d3a989816d1de8446bf9212fe8b4ccc8/docs/src/content/docs/getting-started/first-query.md#L244).

### N02. Make endpoint names and defaults consistent

The CLI defaults to `https://localhost:5514`. The raw daemon and repository example default to `127.0.0.1:8080`. The browser normally uses another listener, 8090. CLI help calls its target only “Server URL.” The connection manual explains the distinction, but a user cannot infer it from the default commands.

Prefer one API port across raw and packaged entrypoints. In help, name the target as the trawld HTTPS API. Print the attempted address in connection diagnostics. Show separately the browser URL and the API URL in all setup output.

Evidence: [CLI help](https://github.com/jakub/trawl/blob/a3422a69d3a989816d1de8446bf9212fe8b4ccc8/crates/trawl-cli/src/lib.rs#L31), [daemon default](https://github.com/jakub/trawl/blob/a3422a69d3a989816d1de8446bf9212fe8b4ccc8/crates/trawl-config/src/lib.rs#L1063), [sample listener](https://github.com/jakub/trawl/blob/a3422a69d3a989816d1de8446bf9212fe8b4ccc8/config/trawld.toml#L9).

### N03. Give each example config one clear purpose

`config/trawld.toml` claims that all shown values are defaults, yet supplies development database addresses on port 5433 and has no browser section. Its database setup comments refer to the old cutover. The Debian config and chart have different deployment assumptions.

Provide a minimal standalone starter with clearly marked required inputs, and a separate full settings reference. Label development examples as development examples. Explain which executable reads each file, where the package installs it, and which environment variables override it.

Evidence: [sample purpose and listener](https://github.com/jakub/trawl/blob/a3422a69d3a989816d1de8446bf9212fe8b4ccc8/config/trawld.toml#L1), [database configuration](https://github.com/jakub/trawl/blob/a3422a69d3a989816d1de8446bf9212fe8b4ccc8/config/trawld.toml#L100).

### N04. Replace migration lore in shipped configuration and diagnostics

The chart still describes a transitional SQLite store and future PostgreSQL work. Main and Debian examples say per-role rate limits will return in a future slice even though `rate_rpm` overrides exist. Config and startup errors, package comments, and the deployment skill refer to the removed Fleet cutover runbook.

State current responsibilities and corrective actions. Database errors should point to database provisioning. Shared-session setup should point to current access documentation. A quota error should name the supported fields without requiring an ADR number. Describe what is on the PVC accurately so the backup instructions make sense.

Evidence: [chart architecture claim](https://github.com/jakub/trawl/blob/a3422a69d3a989816d1de8446bf9212fe8b4ccc8/chart/trawl/values.yaml#L3), [sample rate-limit promise](https://github.com/jakub/trawl/blob/a3422a69d3a989816d1de8446bf9212fe8b4ccc8/config/trawld.toml#L90), [startup error](https://github.com/jakub/trawl/blob/a3422a69d3a989816d1de8446bf9212fe8b4ccc8/crates/trawl-server/src/state.rs#L576), [stale skill link](https://github.com/jakub/trawl/blob/a3422a69d3a989816d1de8446bf9212fe8b4ccc8/.agents/skills/trawl-deploy/SKILL.md#L47).

### N05. Explain how a user obtains the login credential

The login form requests an API key but gives no route to acquire one. A new user cannot tell whether there is a default account, registration, a token in startup output, or an operator command.

Add concise help for users and operators. For example, ask users to obtain a personal API key from their Trawl operator, and link operators to first-key provisioning. Keep that help in the Trawl wrapper or an optional shared component slot because Fleet UI also serves Coastwatch.

Evidence: [shared login](https://github.com/jakub/trawl/blob/a3422a69d3a989816d1de8446bf9212fe8b4ccc8/crates/fleet-ui/src/login/component.rs#L57), [Trawl wrapper](https://github.com/jakub/trawl/blob/a3422a69d3a989816d1de8446bf9212fe8b4ccc8/crates/trawl-web-ui/src/pages/login.rs#L54).

### N06. Give empty search states a concrete next step

The initial result view says “No fish in this net yet” and asks the user to type a query. Zero matches get the same metaphor without guidance. The initial hint also hardcodes a Mac shortcut.

Offer a bounded executable example and a query-guide link before the first query. After zero matches, say that no events match and suggest checking time range and filters. Only claim that no events have been ingested when the application has evidence for that statement. Use the appropriate platform shortcut.

Evidence: [initial state](https://github.com/jakub/trawl/blob/a3422a69d3a989816d1de8446bf9212fe8b4ccc8/crates/trawl-web-ui/src/components/results_table.rs#L88), [zero matches](https://github.com/jakub/trawl/blob/a3422a69d3a989816d1de8446bf9212fe8b4ccc8/crates/trawl-web-ui/src/components/results_table.rs#L187).

### N07. Explain Save's scope in the save dialog

Save captures editor text. Export uses the effective query. The manual explicitly states that Save omits the sidebar filters and range control, but the dialog only shows query text and a name field.

Someone who filters nginx errors for the last hour can reasonably expect Save to preserve that search. Explain the omitted state before they save, and point to a shared link for the full browser state. An action to include filters would require a product decision; the current behavior is intentional, not an implementation defect established here.

Evidence: [Save capture](https://github.com/jakub/trawl/blob/a3422a69d3a989816d1de8446bf9212fe8b4ccc8/crates/trawl-web-ui/src/pages/search.rs#L572), [dialog](https://github.com/jakub/trawl/blob/a3422a69d3a989816d1de8446bf9212fe8b4ccc8/crates/trawl-web-ui/src/components/save_as_net_modal.rs#L102), [documented scope](https://github.com/jakub/trawl/blob/a3422a69d3a989816d1de8446bf9212fe8b4ccc8/docs/src/content/docs/use/saved-reports.md#L19).

### N08. Make the collector's collection policy explicit

The Debian base contains homelab-specific noise suppression. Its catch-all excludes application logs whose service fragments are optional. File-source fragments start at the end of files. These are choices about what data the user receives, not incidental implementation details.

Make suppression an explicit optional policy. Explain that the user must install the relevant fragment to collect excluded application logs, and that the file sources collect newly appended lines rather than import existing history. The serial-console rule also merits a fixture: normalization preserves `@`, while the rule compares a hyphenated service name.

Evidence: [base exclusions](https://github.com/jakub/trawl/blob/a3422a69d3a989816d1de8446bf9212fe8b4ccc8/config/vector/debian/base.toml#L66), [noise policy](https://github.com/jakub/trawl/blob/a3422a69d3a989816d1de8446bf9212fe8b4ccc8/config/vector/debian/base.toml#L191), all shipped service fragments. Parser and delivery behavior were not executed.

### N09. Give the deployable collector an explicit certificate-trust setup

The Debian collector ships `verify_certificate = false`. The main guide tells users to turn verification on and supply a CA when appropriate. Copying the deployable example alone therefore bypasses server verification.

Provide a secure deployable example with a clear CA/trust step. Keep any certificate-verification bypass confined to an explicitly selected disposable demonstration. This is a recommendation about a concrete shipped default, not a new claim about an observed incident.

Evidence: [collector TLS default](https://github.com/jakub/trawl/blob/a3422a69d3a989816d1de8446bf9212fe8b4ccc8/config/vector/debian/base.toml#L297), [current trust instructions](https://github.com/jakub/trawl/blob/a3422a69d3a989816d1de8446bf9212fe8b4ccc8/docs/src/content/docs/getting-started/vector-integration.md#L77).

## Compatibility work to consider before freezing 1.0

### C01. Remove automatic pre-1.0 data conversion from normal startup if it is unsupported

`epoch.rs` recognizes markerless old layouts and epoch 2, renames data roots into `.pre-schema-v2` or `.pre-epoch-3`, handles external old WALs, and carries saved report files into the new root. Retention and its public troubleshooting guide contain matching set-aside logic.

If 1.0 accepts only a fresh supported baseline, replace those old conversion branches with clear refusal of incompatible owned data. Keep fresh initialization, current-format validation, safe query-only behavior, durable marker publication, and recovery primitives used elsewhere. Change runtime logic and dependent retention tests/docs together. Do not merely delete the recovery prose while the states remain reachable.

Evidence: [epoch decision table](https://github.com/jakub/trawl/blob/a3422a69d3a989816d1de8446bf9212fe8b4ccc8/crates/trawl-server/src/epoch.rs#L5), [retention coupling](https://github.com/jakub/trawl/blob/a3422a69d3a989816d1de8446bf9212fe8b4ccc8/crates/trawl-server/src/retention.rs#L408), [public troubleshooting](https://github.com/jakub/trawl/blob/a3422a69d3a989816d1de8446bf9212fe8b4ccc8/docs/src/content/docs/operate/retention.md#L72).

### C02. Consider a direct initial application schema

The Trawl store has 17 migrations, including namespace reshaping, old schedule interval repair, and migration-era backfills. Fleet has three migrations, including conversion from the old role-assignment table. Tests explicitly construct intermediate pre-cutover schemas.

A direct 1.0 application baseline could remove historical transforms and the tests that exist only to support them. Preserve every final constraint, index, permission rule, and current lifecycle test. Retain a migration runner for 1.x evolution. Evaluate the two schemas separately: Fleet is shared with Coastwatch, and changing its applied migration identities would break existing consumers. This is a design decision, not an instruction to edit applied SQL in place.

Evidence: [old namespace conversion](https://github.com/jakub/trawl/blob/a3422a69d3a989816d1de8446bf9212fe8b4ccc8/crates/trawl-server/migrations/0010_namespace_v3.sql#L1), [schedule repair](https://github.com/jakub/trawl/blob/a3422a69d3a989816d1de8446bf9212fe8b4ccc8/crates/trawl-server/migrations/0017_report_windows.sql#L52), [Fleet migration contract](https://github.com/jakub/trawl/blob/a3422a69d3a989816d1de8446bf9212fe8b4ccc8/crates/fleet-auth/src/migrations.rs#L5). The sibling Coastwatch manifest still points to Trawl's Fleet crates.

### C03. Replace historical config exceptions with current-schema validation

Several config sections accept unknown fields. Tests deliberately preserve parsing of removed `auth_cache_ttl_secs` and `coastwatch_url` keys. In contrast, selected retired rate-limit keys and `auth.db_path` remain deserialization sentinels so they can receive special migration errors.

A fresh product should report an unknown setting instead of silently using a default after a typo. Apply strict validation consistently to the supported current schema, with useful field paths. Remove isolated old sentinels only when doing so cannot make their values silently disappear. A non-starting config-check command would also let operators validate a file before opening databases or listeners; the current daemon CLI has no such mode.

Evidence: [retired rate-limit fields](https://github.com/jakub/trawl/blob/a3422a69d3a989816d1de8446bf9212fe8b4ccc8/crates/trawl-config/src/lib.rs#L201), [ignored old-key tests](https://github.com/jakub/trawl/blob/a3422a69d3a989816d1de8446bf9212fe8b4ccc8/crates/trawl-config/src/lib.rs#L2651), [migration errors](https://github.com/jakub/trawl/blob/a3422a69d3a989816d1de8446bf9212fe8b4ccc8/crates/trawl-config/src/lib.rs#L1662), [daemon CLI](https://github.com/jakub/trawl/blob/a3422a69d3a989816d1de8446bf9212fe8b4ccc8/crates/trawl-server/src/main.rs#L23).

### C04. Define the daemon data path as a directory

The example advertises glob paths for backward compatibility. `base_dir()` stops at the first glob component. The daemon constructs its executor from that base directory. `parquet_glob()` has no production caller in this repository, only tests.

Prefer an explicit daemon directory contract and reject patterns there. Keep actual file/glob selection in the CLI's local-Parquet path. This removes an old input shape whose apparent selection semantics are not passed to the daemon executor.

Evidence: [sample compatibility promise](https://github.com/jakub/trawl/blob/a3422a69d3a989816d1de8446bf9212fe8b4ccc8/config/trawld.toml#L95), [path handling](https://github.com/jakub/trawl/blob/a3422a69d3a989816d1de8446bf9212fe8b4ccc8/crates/trawl-config/src/lib.rs#L227), [executor construction](https://github.com/jakub/trawl/blob/a3422a69d3a989816d1de8446bf9212fe8b4ccc8/crates/trawl-server/src/state.rs#L658). Source tracing only.

### C05. Remove old unlimited-force semantics only with a replacement for incomplete current state

The repin model retains forced jobs with no recorded ceilings as a pre-migration unlimited acceptance. The formatter reconstructs that behavior for old rows, and tests retain it. Current new forced jobs resolve numerical ceilings before execution.

With a fresh schema, make the supported distinction explicit: unforced, not yet planned, or forced with recorded bounds. Remove the historical unlimited state. Preserve nullable fields that represent a current job still being planned or interrupted; they are not all legacy data. This audit did not establish a reachable bypass for newly created jobs.

Evidence: [force model](https://github.com/jakub/trawl/blob/a3422a69d3a989816d1de8446bf9212fe8b4ccc8/crates/trawl-server/src/repin/ceiling.rs#L53), [historical row formatting](https://github.com/jakub/trawl/blob/a3422a69d3a989816d1de8446bf9212fe8b4ccc8/crates/trawl-server/src/handlers.rs#L2097), [refusal behavior](https://github.com/jakub/trawl/blob/a3422a69d3a989816d1de8446bf9212fe8b4ccc8/crates/trawl-server/src/repin/engine.rs#L2094).

### C06. Audit remaining compatibility vocabulary without deleting valid behavior

The API enum still labels `unauthorized` as a legacy compatibility code, while the policy layer normalizes authentication failures to `auth_error`. Audit actual callers before choosing the 1.0 error vocabulary. Do not assume every exported enum variant is an observed public response.

Schedules without a scheduler-owned window are called “legacy” in several internal comments, but Query text is a current supported mode. Rename that description and keep the mode. Likewise, describe the interaction between `log_file` and internal telemetry directly; file logging still has a supported role when internal telemetry is disabled.

The separate catalog `services_backfilled_at` flag originated in an upgrade sequence. Consider whether one current completion record suffices after a baseline reset, but keep corpus/catalog identity checks and conformance for restored or adopted archives.
