## Start with a question

Which services logged errors in the last hour?

```text
_severity>=error last=1h
| stats count() as errors by service
| sort -errors
```

<div class="query-result">
The search selects error events. <code>stats</code> counts them by service, and <code>sort</code> puts the largest count first. Run the same query in the browser or pass it to <code>trawl query</code>.
</div>

Follow the [query tutorial](/use/query-tutorial/) to filter, extract fields,
and compare results. Keep the [DSL reference](/reference/dsl/) open for exact
syntax and comparison rules.

## Choose how much to run

The CLI can read local Parquet with no server. A log installation uses
`trawld` for ingestion and queries, plus PostgreSQL for keys, roles, application
state, and field types. Add `trawl-web` for browser access.

Trawl targets homelabs and small installations. It runs its log corpus on one
node and has no clustering or multi-tenancy. See [requirements and components](/start/overview/)
before choosing a deployment.
