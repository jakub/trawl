## Start with a question

Which services logged errors in the last hour?

```text
_severity>=error last=1h
| stats count() as errors by service
| sort -errors
```

<div class="query-result">
The search selects the last hour's errors, <code>stats</code> counts them by service, and <code>sort</code> puts the largest first. Run it in the browser or with <code>trawl query</code>.
</div>

[Build a query](/use/query-tutorial/) adds filters, columns, and summaries.
The [DSL reference](/reference/dsl/) has the exact syntax.

## Choose how much to run

The `trawl` CLI reads local Parquet with no server. A log installation adds
`trawld`, PostgreSQL, and `trawl-web` for browser access, on one node with no
clustering or multi-tenancy. See [requirements and components](/start/overview/).
