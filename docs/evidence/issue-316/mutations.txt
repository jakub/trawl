=== m2 and the lost-wake class ===
The criterion says m2 "must fail every test converted to controlled cadence time". It does not.
An earlier run of m2 against all seven converted tests and refusals_against_in_flight_charge_wait_for_an_insert
killed only the held-burst test. The other six survived, because each finishes its Open-planned boot pass
(settled record) BEFORE it writes anything that wakes the loop. No wake arrives during an Open-planned
pass, so there is nothing to swallow. Only the held-burst test keeps a normal pass planned under Open in
flight while the burst's wake arrives. Widening m2 to the other tests would be a different mutation.

What the criterion protects is that no converted test survives the loss of the wake it waits for. Three
lost-wake patches cover that, each one removing a different wake source:

  converted test                                              killed by (all HANG-GUARD ONLY)
  the_pass_log_records_a_pass_as_planned_then_settled         none: it waits for no wake (it records the boot pass only)
  a_failing_pass_that_ends_open_still_cools_down              refusal-does-not-wake-the-loop
  a_refusal_before_the_wal_exists_does_not_strand_the_burst   m7
  a_clean_rerun_that_races_in_flight_charge_drains_it_after   m7
  a_normal_pass_held_across_a_burst_keeps_its_pressure_wake   m2, m7
  a_pressure_pass_skips_the_daily_rollup                      m7
  the_normal_deadline_rolls_up_under_held_pressure            m7
  refusals_against_in_flight_charge_wait_for_an_insert        patch 13 (PROMPT, on its generation count)

Verdict for m2 as written: not met. Verdict for the lost-wake class: every converted test that waits for
a wake dies when that wake is lost.
