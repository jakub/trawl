The mutation leaks the field case drawer's poll Interval: on_cleanup
takes the handle out of the StoredValue and forgets it. All four tests
in repin-poll-teardown.spec.ts fail on the interval-count assertion, and
routing.spec.ts passes in the same run. That assertion is the only one
that can see this: the leaked timer's body runs a disposed leptos
callback that no-ops, so the leak issues no HTTP read and throws no
pageerror.

mutation-check.sh refuses to start against a dirty tree and exits 2
if the tree is not clean after it reverts, so a transcript that gets
past its first line and ends with a results table is itself the
proof that the working tree was clean at both ends. ANSI escapes
stripped; otherwise verbatim.
